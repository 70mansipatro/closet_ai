# ClosetAI Backend

A production-ready Express + MongoDB backend for the ClosetAI application.

## Features

- JWT auth with refresh tokens
- Password reset via OTP email
- Clothing CRUD with Cloudinary-backed image uploads
- Outfit CRUD plus AI outfit suggestions
- Trip and packing list management
- Validation, rate limiting, helmet, compression, and error handling

## Scripts

- npm install
- npm run dev
- npm start

## Environment

Copy .env.example to .env and configure your secrets.
