# ClosetAI

ClosetAI is a production-ready Flutter + Node.js starter for an AI-powered digital wardrobe app.

## Included

- Flutter app with modular feature folders and GoRouter navigation
- Authentication screens and app shell
- Node.js/Express backend scaffold with health and auth-ready routes
- Environment configuration template for MongoDB, JWT, Cloudinary, OpenAI/Gemini, and SMTP

## Flutter

Run:

```bash
flutter pub get
flutter run
```

## Backend

Run:

```bash
cd backend
npm install
npm run dev
```

## Notes

- No Firebase services are used.
- The app is designed for future expansion into wardrobe, AI, trips, packing, laundry, calendar, subscriptions, and profile management.
